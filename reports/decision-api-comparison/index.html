Decisions API vs Jev vs Microsoft Decision 1, and what Jev integrations do with no key: research of 13 October 2026

This dated report records the evidence behind release regular-2026-10-13-decision-api-comparison of 13 October 2026. It adds one page, Decisions API vs Jev (TypeSafe AI) vs Microsoft Decision 1, with Cloudflare Clef, and refreshes When Jev fails (no-key and bypass cells for model routing and content moderation), benchmarks (B42 graded B: 38 → 39 graded rows) and Jev alternatives (hosted rows rechecked; 33 substitutes, unchanged). The pool ran nothing: no harness, package, benchmark or API call was run.

Key findings

Decision APIs side by side: Graded results depend on the task: OpenAI's Decisions API ahead on RPG move accuracy (B38); Jev on Portuguese exact judge score (B39); Jev and Microsoft-Decision-1 not separated on routing macro-F1, both ahead of OpenAI (B41).

ReportedresultsDocumentedmaterials; B38 and B39 checked 11 Oct 2026, 05:23 UTC; B41 checked 12 Oct 2026, 05:12 UTC

When Jev fails: With no API key set, of 77 Jev implementations read in source: 43 fail closed, 16 fall back, 7 fail open, 3 are advisory, 8 not recorded. A bypass path (code that never asks Jev) is recorded for 52 of 77; 25 not recorded.

Documentedcode read at the published pins, recounted by script, checked 13 Oct 2026, 05:31 UTC

Benchmarks: On 1,000 five-option logic questions (B42, grade B), Jev answered 817 correctly and OpenAI's Decisions API 612; Jev's answers come from a 22 Sep run, and the answer key is not published.

Reportedresults in the operator's own unitsDocumentedmetric and results files opened at a pinned commit in run 14; pin rechecked 13 Oct 2026, 05:24 UTC
