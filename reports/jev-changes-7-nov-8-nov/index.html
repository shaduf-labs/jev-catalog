What changed for Jev builders, 7 to 8 November 2026

ohmyjev, a Claude Code, pi and omp guard that asks Jev before risky tool calls, released 0.14.0 with a new shadow setting and fewer calls that reach Jev. Its failure handling is otherwise the same. A pi extension that lets Jev pick each request's model was read in source. SubQ's and Cloudflare's data terms were re-read, and TypeSafe's docs index gained one cookbook. TypeSafe's aliases, model IDs, price, signup and credit state did not change.

Key findings

ohmyjev 0.14.0 keeps its gates off by default and adds a shadow setting that logs what lockdown would block without blocking it. Its four other failure cells are unchanged; the failure map still counts 80 implementations.

Of 29 coding-agent integrations read in source, 15 act on Jev's answer, 10 do not and 4 are unsettled. pi-jev-router (pi) picks each request's model and uses the standard model when Jev fails.

ohmyjev 0.14.0: a shadow setting, and fewer calls reach Jev

ohmyjev is a community guard for Claude Code, with adapters for pi and omp. In its lockdown setting it asks Jev whether a Bash command, a file write or a network call is irreversible or leaks data, and denies the call when Jev's answer crosses a threshold. Version 0.14.0 was published on npm on 3 Nov 2026. Its source was read at the commit npm names for it (fbc4ea4) and compared file by file with 0.13.2 (d307c39, read 2 Nov 2026).

  • Unchanged: lockdown is still off by default, so a default install asks Jev nothing. In lockdown mode without shadow the guard still acts on Jev's answer. Documented
  • Not read: the Codex adapter (adapters/codex.ts, present in both versions) and the screens, routing, done-check and compaction handlers. The new bin/ohmyjev.mjs is an install and key tool; its key check sends one Jev request and does not decide on a tool call.

Updated with this reading: when Jev fails, Claude Code and MCP guardrails, coding agents, products and the build hub. The 2 Nov readings stay on those pages as dated history.

pi-jev-router: Jev picks the model for each pi request

@caph42/pi-jev-router 2.0.0 (published 1 Nov 2026) is a community extension for the pi coding agent. It registers a virtual model, jev/auto; for each request it asks Jev whether the task is complex and sends it to the complex or the standard model it was configured with. pi acts on the choice in code: its runtime resolves the virtual model and sends the request to the model the extension returns. Read at 75ad5b7 (the commit npm names; the published file is byte-identical) with pi 1.5.0 at f9a2636. A different, unscoped project with the same name (r33drichards/pi-jev-router) was not read.

  • On a Jev error or timeout (3,000 ms, no retry): fallback, to the standard model on the first routed turn, otherwise the current model is kept.
  • Malformed answer: the same fallback. No key: the same fallback, per request, with no startup error. Below threshold: the standard model (a routing rule; there is no separate confidence cut).
  • Bypass (recorded): compaction summaries, retries, a reused planning model, continuation turns and, in its fixed mode, every turn after the first are routed without asking Jev.
  • Counting: counted on the coding-agents page (it reroutes a model choice and the host enforces it in code, read at a pinned commit). It is shown under "Read in source; not on the failure map yet"; the failure map's 80 are unchanged. Documented

The coding-agents page also lists 19 coding-agent projects seen between 24 Oct and 8 Nov 2026 for Codex, OpenCode, pi and Claude Code, each with one quote, as leads not read in full; further names seen in that period were not sorted. Details: coding agents.

TypeSafe's docs: one new cookbook

TypeSafe's models, Images, quickstart, legal and changelog pages were identical to the 7 Nov copies. Its docs index (llms.txt) added one page, "Verifying LLM answers against their source" (cookbooks/verify_llm_outputs.md), which uses three Noul questions to check whether an LLM's answer follows from the paragraphs it was given and sends doubtful answers to review. The index now lists 6 patterns, 26 cookbooks and 2 demos. The cookbook reports TypeSafe's own figures from jev-1.14.0 on 7 Nov 2026 (1,000 questions answered by gpt-6-luna; the check passed 73% of answers, and 95.7% of those were right) Reported; the pool ran nothing (R28-S15, R28-S16).
