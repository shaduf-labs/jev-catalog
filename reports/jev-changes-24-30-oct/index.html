What changed for Jev builders, 24–30 October 2026

This dated report records what the catalogue rechecked on 30 October 2026, after its previous checks on 24 October 2026, with no check in between. Every dated fact that a builder relies on (access, aliases, prices, routes, catalogs, lookalike sites, the hosted decision APIs compared with Jev, and pinned integrations) was either read again and re-dated, or found changed and given the date range in which the change happened. Facts that were not read again keep their earlier dates. No Jev call was made, no route was called and no account was created.

Key findings

Access: nothing changed on TypeSafe's side that a new user would act on. Signups are open, new accounts get no free credit, the API is operational, jev-latest still gives jev-1.14.0, and jev-1.13.0 still has no deprecation date.

DocumentedTypeSafe's models page, status page, blog, docs quickstart, console sign-in pages and the CEO post, read 30 Oct 2026, 05:14 UTC (R24-S01 to R24-S13); price $0.042 per million input tokens, output free

Hosted decision APIs: three facts changed for other providers (a fourth, Drex's prices, is in the table below). OpenAI's data-controls page now marks the Decisions API eligible for Private Retention and Safety Retention; Microsoft lists regions for Microsoft-Decision-1; SubQ's docs list SubQ Snap 1.1 at $0.04 per million input tokens.

Documentedeach provider's own pages, read 30 Oct 2026, 05:17–05:23 UTC (R24-S203, R24-S206, R24-S42, R24-S212 to R24-S214); prices as published per million tokens, no per-decision arithmetic

Coding agents: acmelabs-15/jev-gate, a Claude Code hook, lets the tool call go ahead when Jev errors, times out after 1.5 seconds, answers malformed or has no key; by default it only logs.

Documentedsource read at commit b3ae111 (20 Oct 2026) on 30 Oct 2026 (R24-S228 to R24-S234); Claude Code's own handling of the hook's answer was not read in source, so the row is not settled and is not on the failure map

Coding-agent hooks: one read in source, ten classed

acmelabs-15/jev-gate (@acmelabs/jev-gate 0.2.1) is a Claude Code plugin with a PreToolUse hook on Bash, Write, Edit, MultiEdit, NotebookEdit and WebFetch. It sends each tool call to Jev with jev-latest by default. Its default mode only logs; in enforce mode it answers "ask" (the default) or "deny". Source read at commit b3ae111 (20 Oct 2026):

  • Hacker News (search): 83 items for "jev" across the six days; none for jev-latest, "jev 1.13", "jev 1.14", "jev 1.15" or a Jev deprecation.
