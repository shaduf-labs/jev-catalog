Bypass cells complete, Jev 1.14 preview and Claude Code guardrails rechecked (16 Oct 2026)

This dated report records the evidence behind the update of 16 October 2026. It settles the last open cells on When Jev fails, records TypeSafe's Jev 1.14 preview and its opt-in experimental features, and rechecks the Claude Code and MCP guardrails. Nothing was run: no account, key, API call or third-party code.

Key findings

When Jev fails: For all 77 counted implementations, every failure cell (no key, error, malformed answer, below threshold and bypass) is recorded from source at pinned commits (16 Oct 2026).

Documentedfrom source at the pins; four bypass cells name a narrower read scope (below); recounted by script, 16 Oct 2026

Bypass: Code paths that never ask Jev are now recorded for all 77 implementations (source read at pinned commits, 16 Oct 2026); for 13 of them the cell is 'none found' in the files read.

Documentedthe map counts the 77 implementations that act on Jev's answer

Jev 1.14: Jev 1.14 (jev-1.14.0) is available as a preview under jev-preview since 14 Oct; jev-latest still points to 1.13, and TypeSafe says it moves "in a week".

2. Access status and home notices

Checked 16 Oct 2026, 05:21 UTC: Documented. The access state is unchanged: signups open with conditions.

  • Signups open; new accounts get no free credit. API operational on the status page (R17-S04).
  • Console: console.typesafe.ai now serves a sign-in page ("Continue with Google", HTTP 200) where it returned HTTP 403 on 14 Oct. No form was submitted (R17-S01).
  • Jev 1.14 preview: released on 14 Oct under jev-preview; jev-latest still points to jev-1.13.0 (R17-S05, R17-S09). Details in section 4.
  • Rate limits: until at least 14 Oct 2026, 16:46 UTC the models page listed 100K tokens per second and 80 requests per second. On 16 Oct 2026, 05:21 UTC it lists no numbers: "Rate limits are set per organization. Your organization's current limits are in the developer console" (R17-S05). This is treated as an access condition, not a notice (editorial decision, 16 Oct). When the text changed is known only as between those two reads.
  • Price: $0.042 per million input tokens for both versions; output free; "Long context costs the same per token" (R17-S05).
  • Latency event: a 45-minute latency event on the us-east-1 regional endpoint was resolved on 14 Oct 2026, 22:52 UTC (status page, R17-S04). It is a timeline entry on access status.
  • Shown on Home (4): new-user credit disabled; Jev 1.14 preview (new); lookalike resellers; images, Box and long context are experimental (new). Retired (1): TypeSafe's Series A announcement, at the end of its seven-day shelf life (checked 16 Oct 2026, 05:24 UTC); it was hidden and never shown on Home (R17-S19).
  • Subprocessors were not rechecked (the trust portal needs a browser render); the 11 Oct value stands.

4. Jev 1.14 preview

Read 16 Oct 2026, 05:21–05:26 UTC: Documented unless marked.

  • Models and aliases: TypeSafe lists Jev 1.14 (jev-1.14.0, "available from October 14, 2026") and Jev 1.13 (jev-1.13.0). jev-latest → jev-1.13.0; jev-preview → jev-1.14.0 (R17-S05). TypeSafe's post: "jev-latest will be updated to jev-1.14.0 in a week. jev-1.13.0 will be available for a while", with 60 days' warning before 1.13 is deprecated (R17-S09).
  • Context: default 64k tokens per request and 32k per question on both versions; 262k with the opt-in TypeSafe-Danger-Zone-Long-Context header (R17-S05).
  • Experimental features, not production-ready per TypeSafe: images (both versions) with the TypeSafe-Danger-Zone-Images header; the Box question type (1.14 only); 262k long context (both). TypeSafe: images and Box "aren't yet up to our standards to call ready for production" (R17-S05, R17-S06, R17-S20).
  • Vendor claims Reported: 1.14 brings "small, subtle improvements to everything", with "the largest gain in multi-lingual support" (R17-S09). Not tested by the pool.
  • Image data terms: not stated on the images page. The models page says requests are not used for training. The post describes an opt-in for jaggedness debugging and says "We will still not train on your queries" (R17-S05, R17-S06, R17-S09).
