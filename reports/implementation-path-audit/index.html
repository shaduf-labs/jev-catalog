File and policy checks

Jevmail

OAuth source requests gmail.readonly. The question and AI SDK call uses typesafe-ai/jev through Vercel, with maxRetries:0 and application retry handling. The parser maps unexpected category choice to promotional and marks a top-two probability gap under 0.15 as low confidence. Thus schema drift can appear as a normal category. The test script and README’s five-sample claim do not prove tests passed; individual test files were inaccessible in this pass. README free-call claims were not re-established from current Vercel terms.

WordPress

The submit hook records WordPress’s would-be decision before holding eligible comments; cron drainage selects up to 20. Assessment and thresholds use 0.75 spam, 0.65 scam, 0.45 hold, 1.5 toxicity hold and 0.50 link assist by default. A non-error malformed response with absent nested answer fields becomes 0.0 in this plugin and could restore would-be approval; whether the separate provider validates before returning is unknown. The process path retains held status after three configured-provider errors. Repository test assertions were inaccessible; README case and timing numbers are creator reports, not pool measurements. An older synchronous provider guide has a different error contract and is not evidence for this plugin’s current async behavior.

QuantDinger

Direct request and response parser check option sets, probability bounds/sum and confidence. The allow/reject expression blocks explicit risk or execution block, or a sufficiently confident paired signal conflict and adverse market regime. A valid data_quality=insufficient is recorded but does not directly block; risk_check=insufficient or execution_quality=insufficient may allow entry. This is an inference from code, not a trade outcome. Audit storage catches database failure, so it is best effort. Mocked tests cover bypass, risk block, malformed/low-confidence fallback and credit denial; they do not establish a TypeSafe invoice, exchange effect or production use. The creator’s six-check diagram differs from five Jev Choice questions in current source.

Builder implication: a typed response is not itself a safety policy. Test malformed, insufficient, low-confidence and provider-error cases using labelled, consented workload data; keep permission, review and irreversible actions in application code. The workload protocol still has blank results.
