Alternatives by layer

Independent model artifacts include Kev, CLM, Open-Jev (Zefan-Cai), system-one (mpuig), NanoJev. A Jev-shaped endpoint does not mean TypeSafe weights or equivalent calibration. LocalJev generates JSON probabilities, not direct logit readout. GPT-AGI/OpenJev starts with a mock and has no shipped endpoint or trained head; it is distinct from Zefan-Cai/Open-Jev. Jeff/GliFormer is distinct from Gestalt-Lab Jeff. Check the layered matrix for licences and limitations.

Use-case boundaries

Project examples include read-only Gmail triage, WordPress comment review, SQL row judgments and document splitting. The official semantic-find cookbook pairs line Choice with answer-presence Noul because Choice alone must pick a line. Candidate extraction chooses observed spans; absent values and exact date logic stay in code. Citation checks are review signals, not independent source verification.
