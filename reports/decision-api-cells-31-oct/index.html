Hosted decision APIs compared: what changed by 31 October 2026

The comparison of Jev with OpenAI's Decisions API, Microsoft-Decision-1 and Cloudflare's Clef had 40 cells whose latest check date was before 17 October 2026. On 31 October 2026 each was read again at its source where the source could be read. This report lists what changed, what was re-read and found unchanged, and what was not re-read, with the source and time for each. It also records the hosted rows on Alternatives, a new framework package read in source, and the day's access check.

Key findings

Microsoft now lists Decision-1 limits by subscription tier from 2,160 requests and 2.16M tokens per minute (Tier 1) to 15,000 requests and 15M tokens per minute (Tier 6). On 13 Oct 2026 the same page listed 60 to 900 requests per minute and no token limit.

DocumentedMicrosoft Foundry quotas page, checked 31 Oct 2026, 05:20 UTC (R25-S244, R25-S46); changed between 13 Oct and 31 Oct 2026, and Microsoft's page shows no new update date

Cloudflare's data-usage page (updated 16 Oct 2026) says "Zero data retention: Workers AI processes Customer Content only for as long as needed to provide the service", with exceptions (storage services, AI Gateway logging or caching); no period in days is stated. On OpenRouter, Clef-flash is now also served by Makora and DeepInfra; on a non-Cloudflare host your data goes to that host, not to Cloudflare.

DocumentedCloudflare data-usage page, read 31 Oct 2026, 05:14 UTC (R25-S239); OpenRouter endpoints, checked 31 Oct 2026, 05:19 UTC (R25-S42). Host lists only: the hosts' own terms were not read

OpenAI's Decisions API guide now says it "evaluates text, images, and JSON". A per-request image limit was not found in the guide, API reference or changelog on 30 or 31 Oct 2026; the 13 Oct 2026 reading showed up to 128 images per request. Upright's Eevo now lists $0.10 per 1M input tokens in Direct mode and its SystemOne-compatible API, and $0.15 per decision in Default mode.

DocumentedOpenAI guide, API reference and changelog, 31 Oct 2026, 05:11–05:12 UTC (R25-S206 to R25-S210); Eevo pricing page and announcement, 05:13 UTC (R25-S221, R25-S222). Prices as published; no per-decision arithmetic

Jev's own column did not change: price, limits, data terms, errors and routes read the same as when last checked.

DocumentedTypeSafe models page, legal pages and route listings, 31 Oct 2026, 05:11–05:16 UTC (R25-S05, R25-S12b, R25-S19 to R25-S30)

Framework packages: one new row, two newer versions

The framework comparison now has 7 packages read in source: 4 are pre-1.0 and none comes from TypeSafe; 5 raise Jev errors to your code, and 2 decide by themselves. Documented

  • TanStack AI, @tanstack/ai-typesafe 1.0.0 (TanStack; read at commit 5651e07, tagged 22 Oct 2026): raises to your code on an API error, a malformed answer or a missing key; sets no timeout of its own (a 30 s default is documented but not used). Your code decides; the package does not (R25-S227 to R25-S237).
  • Pydantic AI, pydantic-ai-slim 2.64.0 (31 Oct 2026): failure path unchanged, still raises to your code. New: an error status that a retrying HTTP transport gives up on now raises ModelHTTPError (R25-S38, R25-S39).
  • Effect, @effect/ai-typesafe 4.1.1 (30 Oct 2026): failure path unchanged, still raises AiError; no retry or timeout added. New: image and Locate (Box) decisions, the jev-1.14.0 model ID; a malformed response is now InvalidResponseError (R25-S40).

Not part of the failure map on when Jev fails: framework packages leave the decision to your code, so the map's 80 implementations and its counts are unchanged.

Access on 31 October

No change for a new user: signups are open, new accounts get no free credit, the API is operational, jev-latest still gives jev-1.14.0, and jev-1.13.0 still has no deprecation date (checked 31 Oct 2026, 05:11 UTC; R25-S01 to R25-S13). TypeSafe's status page lists one new, resolved event: a "System overload" on the us-east-1 API endpoint on 30 Oct, degraded for 1 hour and 15 minutes and resolved at 21:15 UTC (R25-S04). The home page's notice about the jev-latest move ended its seven-day shelf life; the fact stays on versions and aliases. Details: access timeline. Documented

  • The graded-test cells (Decision-1's B41 row and the card's graded tests): not re-read; no benchmark was run.
