What changed for Jev builders, 31 October to 2 November 2026

One row on the failure map was read again at a new version: ohmyjev 0.13.2 now runs its Jev gates only when a setting called lockdown is on, and it is off by default. A third-party route, OpenCode, lists a free Jev ID. TypeSafe itself changed nothing a new user would notice. This report gives each change with its source and time, what was re-read and found unchanged, and what was not checked.

Key findings

From 0.13.2, ohmyjev's Jev gates run only with lockdown on, which is off by default; with lockdown on, a Jev error, bad answer or missing key still lets the call through.

Documentedohmyjev source read at commit d307c39 (npm 0.13.2, published 29 Oct 2026), 2 Nov 2026, 10:50–10:51 UTC (R26-S20 to R26-S24). Source read only; the pool did not run the plugin

OpenCode's docs list jev-1.13-free, priced "Free" for input and output and "available on OpenCode for a limited time"; OpenCode, not TypeSafe, runs it and does not say which Jev version it serves.

DocumentedOpenCode docs, read 2 Nov 2026, 10:47 UTC and again 10:58 UTC (R26-S200, R26-S38). Third-party route; not run by TypeSafe. Not tested by the pool

TypeSafe: no change. jev-latest and jev-preview still give jev-1.14.0, jev-1.13.0 still has no deprecation date, the price is still $0.042 per million input tokens, new accounts still get no free credit, and the status page lists no event between the two checks.

DocumentedTypeSafe models, images and quickstart pages identical to the 31 Oct copies, CEO post, status page, 2 Nov 2026, 10:47–10:48 UTC; models page read again at 11:13 UTC, identical (R26-S01 to R26-S15, R26-S43)

The failure map: ohmyjev at 0.13.2

ohmyjev is a community Claude Code plugin (with pi and omp adapters) that asks Jev whether a Bash command, a file write or an outgoing request is safe, and denies the call above its cut-offs. Its row on the failure map was read at commit 78bb82c on 16–21 Oct 2026. Version 0.13.2 (29 Oct 2026) was read at its commit d307c39 on 2 Nov 2026.

A free Jev ID on a third-party route: OpenCode

OpenCode's docs page for its model gateway (now called OpenCode Console; its Terms still call it OpenCode Zen) lists two Jev IDs on one endpoint, https://opencode.ai/inference/systemone/v1/systemone. Third-party route; not run by TypeSafe. It sits outside the six routes compared on where to use and is not counted with them.

  • TypeSafe's own pages: its docs (135 pages listed in llms.txt), homepage and blog index did not mention OpenCode as a route on 2 Nov 2026, 10:49 UTC; the docs name opencode once, as a coding agent Jev does not replace (R26-S215 to R26-S217, R26-S222).
  • OpenRouter: its public model list had no :free Jev ID (452 IDs, 14 ending in :free; 2 Nov 2026, 10:47 UTC; R26-S218).
  • Reported errors (GitHub issues, opened and quoted; reports, not an uptime measure): image requests to the endpoint "always fail with HTTP 400" (anomalyco/opencode #57451, opened 20 Oct 2026); the free model returned 451 "Endpoint is unavailable" (DenisSud/pi-setup #3, 21 Oct); the free variant missing from a client's catalog (can1357/oh-my-pi #15249, 10 Oct); the ID sent to a chat endpoint returned 400 (apmantza/pi-free #637, 25 Oct); "Model `opencode/jev-1.13-free` returns HTTP 400 "Model is unavailable"" (dzhng/jevgrep #63, 28 Oct). All five were open on 2 Nov 2026 (R26-S210 to R26-S214). Reported

The pool did not sign up, use or test this route. On TypeSafe's own API new accounts still get no free credit; see is Jev free?

  • Access: signups open, no free credit for new accounts, API operational (status page "All services are online"; no event listed for 31 Oct, 1 Nov or 2 Nov). Details: access status.
  • Models and price: TypeSafe's models, images and quickstart pages and its legal summary are identical to the 31 Oct copies; the four legal pages show the same "Last updated" dates (R26-S03, R26-S05, R26-S06, R26-S15, R26-S25).
  • The six routes: TypeSafe, OpenRouter, Vercel, Opper, Netlify and Cloudflare list the same Jev IDs; Opper's typesafe/jev-latest still gives jev-1.13.0 (10:54 UTC; R26-S26 to R26-S30). Details: versions and aliases.
  • Lookalike sites: the three sites named by Eye Security still answer, and the report still names them (R26-S14).
  • Comparison cells: the Jev column and the cells re-read for OpenAI's Decisions API, Microsoft-Decision-1, Cloudflare's Clef and SubQ Snap read the same as on 31 Oct (their sources re-fetched 2 Nov 2026, 10:54 UTC; R26-S35 for Decision-1 on OpenRouter). The other cells keep their 31 Oct dates; they fall due on 14 Nov.
