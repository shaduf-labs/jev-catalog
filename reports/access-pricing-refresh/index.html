Jev access, pricing, and availability refresh

Run run:6ee2dcc6-09c0-4f2a-8e92-6d6835767621 revisits the official TypeSafe route, current model record, legal/data terms, named gateways, and the independent hosted proxy. It refreshes access facts without upgrading the separate product-adoption finding.

Executive answer: TypeSafe's current model page names Jev 1.13 (jev-1.13.0) at $0.042 per million input tokens with free output. The documented endpoint is POST https://api.typesafe.ai/v1/systemone; jev-latest and jev-preview currently alias the pinned model. Published limits are 250,000 tokens/second and 1,200 requests/minute, with a 64k request context and a 32k state-plus-longest-question limit. The console login and the public Join Waitlist path do not prove that every new account receives credits or API access.

Legal and data boundary

Not training is not the same as not processing. The checked TypeSafe pages say Input is not used to train or fine-tune models without consent. The MCA and privacy materials still describe service delivery, fee calculation, telemetry, fraud/abuse, legal purposes, service-provider disclosure, US hosting, and retention as reasonably necessary. The DPA supplies processor, subprocessor, transfer, and purpose-based retention terms for the relevant customer arrangement. Enterprise zero-data-retention is separate.

OpenRouter, Cloudflare, Vercel if reachable, and the independent proxy each add a provider/account boundary. Do not copy direct TypeSafe price or data assumptions into a gateway row without direct evidence.

Builder reading

  1. Start direct if the console grants access. Pin jev-1.13.0, send only the text state needed for the decision, and test the state-plus-question limit.
  2. Use OpenRouter as the clearest listed fallback. Budget for its separate account and data boundary; verify current provider status, quota, and logging controls.
  3. Use Cloudflare for its account or Workers integration. Check the dashboard price and Cloudflare/TypeSafe terms instead of inferring them from the direct rate.
  4. Keep Vercel unverified and the proxy convenience-only. The independent proxy's $0.42/M is ten times the official displayed rate and does not become official by using a compatible endpoint.

Remaining gaps

  • TypeSafe's public pages do not show a logged-in account's credit balance, quota, or self-serve eligibility; the Join Waitlist surface remains visible.
  • Cloudflare dashboard pricing and account-level retention controls were not public in the checked model page.
  • The named Vercel page was inaccessible; OpenRouter account-specific quotas and data controls were not confirmed.
  • The independent wrapper's terms/data-retention page and live /get-jev route were not accepted as evidence.
  • This run refreshed access and pricing only. The bootstrap finding remains: no checked public source established a verified commercial production product using Jev.
