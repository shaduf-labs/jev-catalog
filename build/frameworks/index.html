Jev LangChain and other framework integrations (TypeSafe AI)

When the pool checked search suggestions on 5 Oct 2026, 05:14 UTC, Google, Bing and DuckDuckGo all offered "jev langchain". "jev pydantic", "jev spring ai" and "jev llamaindex" had no suggestions on any of the three. A suggestion shows that people search for a phrase, not how many do. This page reads six framework packages for Jev in source: LangChain for Python and for JavaScript, Pydantic AI, Effect, Spring AI and LlamaIndex. It shows who publishes each one, how young it is, and what it does to your code when the Jev call fails.

Key finding

Of 6 Jev framework packages read in source, 4 are pre-1.0 and none comes from TypeSafe; 4 raise Jev errors to your code, while the community Spring AI filter passes passages through unscreened.

Documentedsource at pinned tags and commits, checked 5 Oct 2026

Picked from framework packages builders asked about ("jev langchain") and those named in the research plan; not a survey. The pool installed none of them, ran nothing and made no Jev call. The 4 that raise errors are the LangChain Python and JavaScript classifiers, Pydantic AI and Effect.

  • fail-open: acts anyway (unscreened passages reach the prompt)
  • fallback-<what>: a stated substitute (here the retriever's order)
  • no-decision: raises; your code must handle it
  • conditional: depends on how it is set up
  • 4/6pre-1.0 (0.0.1a3, 0.0.2, 0.4.0, 0.1.1). Effect is 4.0.1 but marked unstable; Pydantic AI ships in 2.54.0
  • 0/6published by TypeSafe (framework vendor 4/6, community 2/6)
  • 4/6raise Jev errors to your code (LangChain Python and JS classifiers, Pydantic AI, Effect)
  • 2/6decide by themselves and do not stop on a Jev error (Spring fail-open, LlamaIndex fallback-retriever order)

The two LangChain packages also contain middlewares that decide by themselves; all three fail closed (Python AutoMode and ModelRouter, JS autoMode). They are counted inside their package, not as extra packages.

Corrections to earlier research facts

  • langchain-typesafe 0.0.1a3 was uploaded on 20 Sep 2026, 18:54:39 UTC, not 4 Oct (PyPI).
  • @effect/ai-typesafe is now 4.0.1 (4 Oct 2026, 21:51 UTC), not 4.0.0.
  • The Spring AI integration is community-published (org.springaicommunity:typesafe-spring-ai 0.4.0). It is not part of spring-projects/spring-ai.
  • AutoModeMiddleware is inside langchain-typesafe (experimental module). A separate JS version ships in @langchain/typesafe 0.0.2.
  • LlamaIndex has a community integration (llama-index-postprocessor-jev and -selectors-jev 0.1.1). Nothing official was found (where we looked).

Thresholds and known issues that change behaviour

How to pick your own threshold is on how to choose a confidence threshold. Status codes and retries are on errors and rate limits. Documented source at the pins; issue counts from GitHub search, 5 Oct 2026, 05:17 UTC

  • LangChain Python middlewares. AutoMode blocks at risk ≥ 0.5; the value is hard-coded. ModelRouter always takes the chosen model, with no confidence cut. Source observation, not filed as an issue: AutoMode passes criteria=None explicitly, so its default criteria are never applied, and no test covers this. Open issues include #40694 (classifies calls that inner middleware can rewrite) and #40700 (ModelRouter overrides the ModelFallbackMiddleware model). The failure path is tested.
  • LangChain Python classifier. 13 open issues with "typesafe" in the title, including #40706 (empty questions sent) and #40867 (no retry or rate-limit handling).
  • LangChain JS. autoMode cuts at a fixed 0.5. Tools you do not list are never sent to Jev. 0 open issues.
  • Pydantic AI. Booleans are thresholded at 0.5. Routes have a threshold that defaults to 0.0; when you set one, it raises UnsureRoute. Open issues include #9640 (state always sent as text) and #9641 (LLMJudge drops the probability).
  • Effect. Threshold left to you. A missing answer key is silently skipped. 0 open issues.
  • Spring AI filter. Default policy thresholds: injection 0.70, contradiction 0.70, relevance 0.45, evidence 0.55. A passage whose injection score is below 0.70 is kept. 4 open issues (#3, #7, #21, #27); #27 affects advisors, not RAG.
  • LlamaIndex reranker. The optional confidence_threshold (default none) only sets a metadata flag and never drops nodes. Issues not checked.

On a Jev error, 1 of these 4 rows lets the action go ahead: Spring, where passages the injection screen could not judge enter the prompt. The LlamaIndex fallback returns the retriever's order by design and is not counted as going ahead, following the checklist's convention for routing fallbacks. Below-threshold results are counted separately from errors.

How these rows were counted

  • JS autoModeMiddleware is a separate row. It is a different package and implementation from the Python AutoModeMiddleware, which stays where it is already counted, on Claude Code and MCP guards. No existing row changes.
  • Pydantic AI is not a decision row. TypeSafeModel returns typed answers to the agent you write and raises on a Jev error, so your code decides what happens next. Its failure behaviour is on this page only.
  • The Python classifier and Effect are not decision rows either: they raise to your code.
