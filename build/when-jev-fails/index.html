When Jev fails (TypeSafe AI)

What do real Jev implementations do when Jev returns an error, a malformed answer or an unsure answer, when no API key is set, or when a code path skips Jev? This page counts the answers across 80 implementations in twelve use cases, already published row by row on their domain pages, and turns them into an eight-question checklist for your own code. The title is an internal label: six failure phrases ("jev fallback", "jev timeout", "jev error handling", "jev fail open", "jev retry", "typesafe api error") got no relevant autocomplete suggestion on Google, YouTube, Bing or DuckDuckGo when the pool checked on 4 Oct 2026, 05:21 UTC.

Key finding

For all 80 counted implementations, every failure cell (no key, error, malformed answer, below threshold and bypass) is recorded from source at pinned commits (19 Oct 2026).

Documentedeach of the five columns sums to 80 with 0 not recorded (script count over the map below), checked 19 Oct 2026

Of 80 Jev implementations read in source, on a Jev error 40 stop or hold the action, 22 fall back, 10 let it through, 5 return no decision and 3 are advisory. The 10 that let it through are 4 moderation bots, 4 agent hooks, a passage filter and an eval tool.

With no API key, 51 of 80 implementations refuse to start, error or hold; 17 fall back, 9 proceed as if allowed and 3 are advisory (source read at pinned commits; recounted 19 Oct 2026).

Code paths that never ask Jev are recorded for all 80 implementations (source at pinned commits, 19 Oct 2026): 13 "none found" in the files read, 67 with their skip paths listed.

The eval tool is openlayer jevals: its report counts an errored eval as passed and its gate allows by default. Counting 9 fallbacks that can still end in the action as well, the action goes ahead on a Jev error in 19 of 80 (10 fail-open plus 9 fallbacks; details).

"Keep the last action" counts as going ahead: doom-jev and JevPlaysSnakeGame keep acting on a choice Jev did not make for this tick (counting choice, 12 Oct 2026).

The 4 agent hooks are danna-zhou/jev-mcp (PreToolUse hook), claude-model-guard (a model-tier guard, added 18 Oct 2026) and ohmyjev (Bash, Write/Edit and exfiltration gates, added 19 Oct 2026) for Claude Code, and jev-judge for Hermes Agent, in enforce mode (its default is shadow).
