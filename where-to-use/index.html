Where can I use Jev, and at what price?

Access routes are not interchangeable. The official model, a gateway, and an independent proxy can have different endpoints, billing, accounts, and data boundaries.

Checked 20 September 2026: TypeSafe's launch materials report $0.042 per million input tokens and free output, with 70–500 ms vendor-reported latency. Treat this as a dated vendor claim; confirm the current console, model, limits, and terms before use.

Before you put data through it

  • Confirm the provider, model ID, endpoint, input/output billing, quota, waitlist, and current terms on the live provider page.
  • Ask where state is processed, logged, retained, or used for improvement. The checked sources did not establish a complete cross-provider data policy.
  • Send only the state needed for the judgment; batch questions when the provider says they share a state and round trip.
  • Pin a model version if thresholds matter, and keep a fallback when the model or gateway is unavailable.
Cost intuition: input-token pricing is not per “decision” in the abstract. The state and question text determine token use; gateway markups, minimums, quotas, and proxy pricing can change the real bill.
