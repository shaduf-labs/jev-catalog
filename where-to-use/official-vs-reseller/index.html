Is this Jev site official? TypeSafe domains vs lookalike resellers, with prices

Within a week of Jev's launch, hundreds of new "jev" domains appeared. Some resell real Jev access at several times TypeSafe's price, some are information sites or playgrounds, and none of them is TypeSafe. This page lists the official surfaces, a five-step check, and what each reseller displayed on 28 September 2026.

Short answer

TypeSafe's own surfaces are typesafe.ai and its subdomains, the github.com/typesafe-ai organisation, and the packages typesafe-sdk (PyPI) and @typesafe-ai/sdk (npm). The official price is $0.042 per million input tokens with free output. Eye Security (25 Sep) found lookalike reseller storefronts charging 3–11.5× that price; on 28 Sep one pack on jevmodel.org displayed 15.7×. Eye Security wrote that this "isn't illegal as far as we can tell" and did not call the sites malicious.

Five-step check

  1. Domain. Is it typesafe.ai or a subdomain (docs., console., api., status.)? Eye Security's advice: "check that you're on console.typesafe.ai, not just a site with Jev in its name".
  2. Packages and code. Is it typesafe-sdk or @typesafe-ai/sdk, with code under github.com/typesafe-ai? The github.com/TypeSafeAI organisation, the PyPI package typesafe-ai and the unscoped npm package n8n-nodes-typesafe-ai are not TypeSafe's; TypeSafe's n8n node is the scoped @typesafe-ai/n8n-nodes-typesafe-ai.
  3. Key. Does the key come from console.typesafe.ai or a named gateway (OpenRouter, Vercel, Cloudflare, Netlify, Opper)? A reseller's key is not a TypeSafe key; jev-agent.org, for example, "provisions a Jev Agent key rather than an official TypeSafe API key".
  4. Price. The official price is $0.042 per million input tokens and output is free. Any higher per-token price is a markup.
  5. Operator and data. Does the site name its operator and state any affiliation? What does it ask for: card, key, prompts? Eye Security found reseller traffic passing "an app on Railway behind Cloudflare" with "no contract or SLA". Never paste your TypeSafe key into a third-party site; jev.works asks for one. How official routes handle your prompts, by contrast, is quoted on data handling by route.

What the security researchers actually said

The primary source is Eye Security, "Rise of the Jev-Clones" (25 Sep 2026). GBHackers, Cyber Security News and Mallory (28 Sep) report on it. Reported

  • About 670 new "jev" domains received certificates between 15 and 22 Sep, and about 40 "typesafe" domains between 16 and 21 Sep.
  • The storefronts sell real TypeSafe Jev with a markup of 3× to 11.5×.
  • Eye calls them "fake storefronts" and a "rip-off", but also writes: "This isn't illegal as far as we can tell."
  • Cyber Security News: the report "does not describe a malware infection or establish that operators stole prompts."

This site therefore calls them lookalike reseller storefronts (Eye Security, 25 Sep). No named security source calls any of these domains malicious. jevtypesafeai.com also has a "Jev on AWS Bedrock" page; Jev is not listed in the Amazon Bedrock model cards at 5 Oct 2026, 05:18 UTC (Is Jev on Amazon Bedrock or Azure AI Foundry?).

Recheck, 30 Sep 2026, 20:53 UTC: the Eye Security report is still online and still says "You just pay up to 11.5x the official price"; jev-agent.org, jev-ai.pro and jevtypesafeai.com all answered HTTP 200. Their prices were not re-read, so the prices above keep their 28 Sep date. Reported

Other Jev sites that do not resell tokens

jev-ai.live, jevaiplayground.com, jevplayground.com, typesafe.pro, typesafeai.app and jev.works are information sites, playgrounds or gateways; each states it is independent of TypeSafe. jev-router.com is an independent gateway for open "Jev-class" models and states: "We do not provide access to TypeSafe's Jev model." It is unrelated to OpenRouter's typesafe/jev-router. jev.bevel.software ("EU/Jev") is a Jev-compatible API that serves another model: it states that "eu/jev runs its own model" (jeff-latest), that Jev model IDs return HTTP 400, and that it is "Not affiliated with TypeSafe AI"; it claims inference in Germany and a price of €37 per billion input tokens. It does not resell Jev and does not claim to host Jev, so it is a compatible substitute, not Jev. Reported the operator's own pages, read 3 Oct 2026, 05:30 UTC Also flagged but not opened: the GitHub repository jev-ai-desktop/Jev-AI-Desktop (its description is a keyword list), Hugging Face Spaces under jevaimodel/ and a model named JEV-27B-GGUF. TypeSafe's Jev weights are not public, so any download claiming to be them should be treated with caution. Unverified

What was not verified

  • Who operates each domain: the pool relies on the sites' own statements and Eye Security's report.
  • jev-agent.com, jev-ai.pro's monthly prices, and the full text of the cyberpress article.
  • The flagged repositories and Spaces were not opened. No purchases were made and no prompts were submitted.
  • Displayed prices can change; each carries the 28 Sep check time.
