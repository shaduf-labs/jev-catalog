Jev alternatives (TypeSafe AI): open-source models, local runtimes and hosted APIs, and what each replaces

What can replace Jev (TypeSafe AI): open-weight models, local runtimes, request adapters and OpenAI's hosted Decisions API, by layer and licence. "Alternative" can mean five different things: a different request library, a local runtime, a different trained model, another provider's hosted API, or a different kind of model altogether. Pick the layer you need to replace first; a matching request shape does not mean matching answers. Why this title: Google completes "jev alt" to "jev alternatives"; Bing and DuckDuckGo complete it to "jev alternative" (autocomplete, 10 Oct 2026, 05:17 UTC; R12-S11). A suggestion shows that people search for it, not how many.

Key finding

Jev weights: not found on TypeSafe's site, docs, GitHub or Hugging Face (10 Oct). Of 30 listed substitutes: 12 model weights, 11 local runtimes, 4 request adapters, 2 classifier/LLM approaches, 1 OpenAI hosted API.

Documentedofficial TypeSafe surfaces; each row's layer from its primary source; checked 10 Oct 2026, 05:11–05:20 UTCReportedthe rows' own quality claims

Picked from the research plan's named items and the 8–10 Oct scan, added to the rows already on this page; not a survey of decision models. Counts are table rows by layer; a row with two layers counts once, under its primary layer. The pool ran nothing: no model was downloaded or run and no Jev call was made.

Short answer

Official weights or a local runtime. TypeSafe-published Jev weights or a local Jev runtime: not found on typesafe.ai (no /models page, HTTP 404), the docs (llms.txt, the models page, the introduction), TypeSafe's GitHub organisation (12 repositories: SDKs, an interface adapter, skills, examples, n8n nodes and two forks) or a Hugging Face author search for TypeSafe accounts (0 models), checked 10 Oct 2026, 05:11–05:20 UTC. Documented TypeSafe's docs describe Jev as hosted: "the same weights serve every account". Its new Enterprise page lists the question "Can we run Jev in our own VPC or on-premises?", but the answer is not in the served page and the pool has not read it. (R12-S100–S110, R12-S21, R12-S36, R12-S58)

Can you run Jev in Ollama? Not TypeSafe's Jev on the evidence checked. Ollama's library search for "jev" showed no Jev-named model on its first page (10 Oct 2026, 05:11 UTC), and no TypeSafe weights were found (above). Ollama 0.35 (blog, 29 Sep) runs other Jev-style decision models (nimble from Bespoke Labs; tev1 and tev1:0.8b from Together AI) behind a System One-style endpoint. OllamaMQ v0.5.0 is a queue in front of such servers, not a model. Documented (R12-S107, R12-S135, R12-S136)

Other options. If you need local weights, the independently trained options with inspectable repositories and model cards are Kev, CLM, Laya and Jeff, among others; Kev and CLM also expose a System One-style API. Ollaya (new on 28 Sep) runs several of these models locally behind a System One-compatible API. The pool has run no parity test of its own (nothing run as of 10 Oct 2026); their accuracy figures are the authors' own. Published comparisons with Jev: Opper's Jev–Kev comparison (B11, grade B, operator with a stake) and, as leads not graded, the Jev vs Decisions API vs Laya repository (mateusfonsek) and the Jev vs Decisions API RPG repository (komzweb), checked 10 Oct 2026. Hosted Jev, Laya and Kev are compared on the same rows on Jev vs Laya vs Kev. (This paragraph: rows checked 26 Sep–1 Oct, not rechecked on 10 Oct.)

Another provider's hosted API. Another provider's hosted decision API is a different layer: OpenAI's Decisions API (public beta) runs its own model, gpt-6-luna, behind a different request shape, and your data goes to OpenAI. See the hosted-API layer and its row. (R12-S134, R11-S300)

Choosing between Jev, a general LLM with JSON output and a trained classifier is a different question: see Jev vs an LLM vs a classifier: when to use which. Published accuracy tests, graded by how far they can be checked, are on the benchmarks ledger.

Which layer do you need to replace?

You needChooseDo not choose it if
Keep your request code, change the providerAn API interface adapterYou need data to stay local: adapters forward requests to another provider or model.
Run on your own hardwareA local runtime or independent weightsYou need Jev's calibration or accuracy: local runtimes wrap other models and were not compared on your task.
Open weights you can fine-tune or auditIndependent weights (Kev, CLM, Laya, Jeff…)You cannot check separate code, adapter and base-model licences, or you need more than the model's context (Laya about 512 tokens, CLM 2k by default).
A hosted decision API, but not JevAnother provider's hosted decision API (OpenAI Decisions API, public beta)Your data must not go to that provider, or you need Jev's exact answers (a different model answers).
Free-text output, or you already have labelled dataAn LLM with structured output, or a trained classifier (10 criteria compared)You need per-option probabilities without training.

Opper's 25 September article, with benchmark code, a 362-item manifest and results, reports one run on 160 arXiv labels, 120 Stack Exchange sites and 82 GitHub issue labels. Reported It is row B11 (grade B; flags COI, small-n) on the benchmarks ledger.

What was not verified

  • Same-workload, same-hardware parity test of any alternative against Jev: none run by the pool as of 10 Oct 2026; the published comparisons are B11 (Opper, grade B) and two Decisions API leads, not graded (checked 10 Oct 2026).
  • Base-model licences and some checkpoint and adapter licences (JevAny adapters, vjev-vision): not established; not rechecked since 1 Oct 2026.
  • "Local" is not a privacy guarantee: check downloads, network calls, logging and retention for each project.
  • Rows keep their own check dates (22 September–10 October). On 1 October only Kev and Laya were rechecked; on 10 October only Strands Decider was rechecked and Jiwo 0.8B, TOD and the Decisions API were added.
  • Not read on 10 Oct: the Enterprise page's on-premises answer; the second page of Ollama's search; the Strands LICENSE.md text (metadata only), strandsagents.com and the Gemma 4 base licences of the Strands variants; TOD's base-card licence and its hosted API shape; OpenAI's pricing page (only the guide was read).
  • All authors' accuracy figures, including those of Jiwo 0.8B, TOD and Strands Decider, are their own. The Decisions API comparison leads are not graded: code and data present at pin; metric code not yet opened.
  • Strands Decider's AWS link: no aws.amazon.com source and no AWS-organisation GitHub source was found (10 Oct 2026, 05:13 UTC); the strands-labs GitHub organisation is unverified and has no description.
  • The pool ran nothing: no package installed or run, no model downloaded, no benchmark run, no Jev call.
  • Ollaya's per-model licences, the origin of its benchmark and Kev-9B's base licence were not checked. Laya's and Kev's System One compatibility is stated by their authors, not tested by the pool.
