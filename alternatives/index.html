Open-source alternatives to Jev

There is no checked open-weight Jev here. These projects substitute for different layers: the API shape, the hosted model, the local runtime, or the underlying classification job.

Read the column that matters: a compatible interface is not the same as the Jev model; a local classifier is not the same as calibrated System One decisions; an adapter is not a new model.
ProjectWhat it actually offersWhat it substitutes forWhat it does not prove
system-one-adapter-python
official adapter		TypeSafe's Python repository keeps a similar system_one evaluation interface but calls OpenAI/Anthropic-style providers.SDK shape and comparison workflow.It is not Jev weights, training, latency, price, or calibration.
SemIf / OpenJev
local open model		Reads option probabilities from an open model in one pass; the README says it is independent and not affiliated with TypeSafe.Local/private Jev-like interface and runtime.Parity with Jev's undisclosed model or training.
jevlike
research project		A trainable starter model that chooses among changing text options and returns probabilities.A trainable local option-scoring architecture.A Jev replica, commercial reliability, or equivalent calibration.
mini-Jev
teaching bench		A frozen Qwen3-4B experiment that reads option-letter logits instead of generating JSON; MIT licence is stated.A local experiment for decision-native scoring.A drop-in model; its README says the scores are not calibrated probabilities and the evaluation is narrow.
GLiClass
classifier		Apache-2.0 zero-shot sequence classification with local model weights and label scores.Local zero-shot classification when deployment control matters most.Choice/Score/Noul API compatibility or Jev's calibration and performance.
General LLM + structured output
baseline		Ask a generative model for a schema-constrained JSON answer when the task also needs text or flexible output.The decision step, sometimes with a familiar hosted API.It does not remove parsing, retries, refusal, token cost, or model-output uncertainty.

Choose by the constraint

Need the real Jev model?

Use TypeSafe's official route or a gateway that currently lists it. An adapter or local project is not equivalent.

Need local or private execution?

Try SemIf, mini-Jev, GLiClass, or a task-specific classifier. Accept that you are changing the model, calibration, hardware, and maintenance burden.

Need one code path for comparison?

Use TypeSafe's adapter against another LLM. Compare accuracy and cost on your workload, not only API shape.

Need open-ended output?

Use a generative LLM, optionally preceded or followed by Jev. Jev is the branch, not the explanation.

Open-source finding: the projects above are useful substitutes for a layer of the problem, but none checked here is the Jev model. Verify licences, model weights, device requirements, and evaluation scope directly before building a dependency.
