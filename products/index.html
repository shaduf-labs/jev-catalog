Jev examples: products and projects built with Jev (TypeSafe AI), graded by evidence

This is an evidence ledger, not a customer list. Each project is graded by what the pool could check: whether it read the code that calls Jev, only the project's description, or a mocked demo. Google, YouTube, Bing and DuckDuckGo all suggested "jev examples" in autocomplete on 3 Oct 2026, 05:22 UTC; none of them suggested "jev products". This page answers that search with graded rows rather than a showcase.

Key finding

Of 96 ledger rows on 10 Oct 2026, the pool read the Jev call in source for 83; none of the 96, nor 7 published claims, is independently verified as running in production.

Grade A means the pool read the code path that calls Jev at a stated commit. It does not mean the project runs, has users or works well.

Short answer

As of 10 October 2026 the ledger has 96 rows (recounted 10 Oct 2026; 94 on 8 Oct, 92 on 6 Oct). For 83 of 96 the pool read the code that calls Jev at a pinned commit (grade A); 12 of 96 rest on the projects' own descriptions (B); 1 of 96 is a mock (C). Independently verified in production: 0 of 96. Seven published production or cost claims are listed with what their sources show. None is independently verified in production. This does not mean none exists.

The rows include a Gmail sorter, a WordPress moderation plugin, a trading gate, SQL extensions, browser agents, Claude Code, MCP and agent-guard integrations, and, added on 3 Oct, 24 ticket-triage, model-routing, moderation, email and n8n projects. On 4 Oct, 6 trading, fraud, expense-approval and judging projects were added and 2 trading bots moved from B to A. On 5 Oct, 5 browser and computer-use projects were added and 3 moved from B to A. On 6 Oct, 18 coding-agent integrations (Codex, OpenCode, Cursor, Hermes Agent, OpenClaw) and 2 Claude Code guard rows were added, all grade A; the selection is the rows read for build/coding-agents plus the two guard rows, not a survey of coding-agent plugins. On 8 Oct, 2 rows were added (LanceDB TypeSafeReranker and pg-redact) and jev-reranker (Python) moved from B to A after its v0.1.2 code was read; see reranking and RAG and Jev inside SQL and document pipelines. On 10 Oct, 2 more coding-agent integrations were added, both grade A: jev-effort-router (a Hermes Agent plugin that sets the model and reasoning effort per turn) and jev-gateway (an npm proxy in which Jev picks the tool for Codex, OpenCode, Claude Code, Kilo, Gemini and Devin). Two of the 96 are official TypeSafe: the Claude Code plugin, which makes no Jev call, and the n8n node. One of the 96, @openclaw/typesafe, is published by a host vendor (OpenClaw), not by TypeSafe.
