Jev examples: products and projects built with Jev (TypeSafe AI), graded by evidence

This is an evidence ledger, not a customer list. Each project is graded by what the pool could check: whether it read the code that calls Jev, only the project's description, or a mocked demo. Google, YouTube, Bing and DuckDuckGo all suggested "jev examples" in autocomplete on 3 Oct 2026, 05:22 UTC; none of them suggested "jev products". This page answers that search with graded rows rather than a showcase.

Key finding

Of 61 ledger rows on 3 Oct 2026, the pool read the Jev call in source for 39; none of the 61, nor 7 published claims, is independently verified as running in production.

Documentedledger countsReportedpublished claimschecked 3 Oct 2026

Grade A means the pool read the code path that calls Jev at a stated commit. It does not mean the project runs, has users or works well.

Short answer

As of 3 October 2026 the ledger has 61 rows. For 39 the pool read the code that calls Jev at a pinned commit (grade A); 21 rest on the projects' own descriptions (B); 1 is a mock (C). Seven published production or cost claims are listed with what their sources show. None is independently verified in production. This does not mean none exists.

The rows include a Gmail sorter, a WordPress moderation plugin, a trading gate, SQL extensions, browser agents, Claude Code, MCP and agent-guard integrations, and, added on 3 Oct, 24 ticket-triage, model-routing, moderation, email and n8n projects. Two of the 61 are official TypeSafe: the Claude Code plugin, which makes no Jev call, and the n8n node.

What was not verified

  • No project was observed making a live Jev call, and no installation, user count or bill was checked. In this refresh nothing was installed or run and no mailbox or workflow was connected.
  • Grade A means the call path was read at a commit, not that the project runs, has users or works well.
  • Grade B rows were not checked against their code in the run that recorded them; none was re-read in source between 1 and 3 Oct.
  • Creator timing, cost and accuracy figures in project READMEs are their own reports.
  • Rows keep their own check dates (23 Sep to 3 Oct). Repository status on 3 Oct was read from GitHub HTML pages, not the API.
  • Production claims were checked against their own sources only; no company confirmed or invoiced anything to the pool. The two claims relayed by VentureBeat (Vercel's 13% adoption figure and TypeSafe's 140,000 cleared from the waitlist) were not rechecked on 3 Oct.
