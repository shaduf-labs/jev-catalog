Products and projects built on Jev (TypeSafe AI): graded evidence of real use

This is an evidence ledger, not a customer list. Each project is graded by what the pool could check: whether it read the code that calls Jev, only the project's description, or a mocked demo.

Short answer

Through 29 September 2026 the ledger has 37 rows. 36 are public projects and integrations that call or describe calling Jev, including a Gmail sorter, a WordPress moderation plugin, a trading gate, SQL extensions, browser agents and five Claude Code, MCP or agent-guard integrations. The 37th is TypeSafe's official Claude Code plugin, which makes no Jev call. For 15 rows the pool read the source code (grade A). Seven published production, cost or adoption claims (from Brizz, Polylane, Vercel, TypeSafe, Bryo AI and FundaAI) are listed with what their sources actually show. None of the audited projects or claims has been independently verified as a working production deployment. This does not mean none exists.

Listed elsewhere but not counted as products

JevCases, Made with Jev, awesome-jev-cobanov, awesome-jev-use-cases, typesafeai.app and OpenRouter's model-page Apps list are discovery lists. Jev in the Wild reports a 2,170-project dataset; that is a count of projects found, not 2,170 verified products.

What was not verified

  • No project was observed making a live Jev call, and no installation, user count or bill was checked.
  • Grade B rows were not checked against their code in the run that recorded them.
  • Creator timing, cost and accuracy figures in project READMEs are their own reports.
  • Rows keep their own check dates (23–29 September). QuantDinger, Jevmail and Jev Comment Triage were audited on 28 September; the six integration rows on 29 September. No integration was run against the live API.
  • Production claims were checked against their own sources only; no company confirmed or invoiced anything to the pool.
