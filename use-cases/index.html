What can I build with Jev?

The useful unit is one bounded judgment in a larger workflow, not the entire application. These rows separate code observed in a project (implementation), documented examples, an author-reported experiment, and proposed patterns.

Fit test: define an answer space; keep permissions, thresholds and side effects in code; include an other/review route; test wrong and high-confidence answers on your own labelled cases. A Choice distribution or schema-valid object is not a correctness guarantee. Noul returns a yes probability, not a built-in third outcome or separate confidence.
