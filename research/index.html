Jev (TypeSafe AI) catalogue research history and evidence method

Every claim on this site comes from a dated research run. This page lists all reports, newest first, explains the evidence labels, and records what changed in each release, including where every earlier URL now points.

Short answer

15 dated reports cover 20–29 September 2026, the newest being the integration-trust research of 29 September (Claude Code and MCP guardrails, TypeScript, testing without a key). Each is kept unchanged at its original address. Facts on the question pages carry the date of the report that checked them; a later page edit does not re-date an old fact.

Release notes: 29 September 2026

  • New pages: Build hub, TypeScript, Claude Code and MCP guardrails and testing without a key. Each met the research plan's rule for shipping. For example, the Claude Code page needed four or more integrations read at a pinned commit; six were read.
  • Corrections: oh-my-claudecode's 2000 ms Jev timeout exists only on its dev branch; v5.5.0 and main still default to 250 ms. The Products row "jev-mcp" is now "jev-mcp (jkudish)", regraded from B to A and marked advisory.
  • Unchanged, re-dated: signup status, new-user credit, status page, model aliases, the TypeSafe price, the OpenRouter, Vercel, Cloudflare and Opper listings, and both SDK versions.
  • Evidence: 29 Sep integration-trust report.

Release notes: release 1, 28 September 2026

The owner asked for an evidence-backed resource ordered by reader question. Release 1 adds or substantially rebuilds 13 pages and lightly extends two. The reason for each page is in the URL map below. Pages whose evidence was not ready were not published thin: the planned pages on TypeScript, Claude Code and MCP, benchmarks, data handling by route, ticket triage and model routing are scheduled for later releases.

  • Corrections in this release: two project rows were labelled as official TypeSafe repositories but come from the unofficial github.com/TypeSafeAI community organisation; Vercel's exact price is now documented ($0.042 per million in its models API); the "250 ms default timeout" is not TypeSafe's; the confidence formula 2·p_top − 1 applies to two-option Choices only; the $5 new-user credit rests on secondary reports with a conflicting first-hand report.
  • New tool: the cost per decision worksheet, explained on its page.
  • Evidence for this release: release 1 research report.

How pages were chosen: no search data

Search impressions, clicks, query coverage and indexing data, Search Console, keyword volumes and site analytics were not available for release 1 (28 September 2026), and were still unavailable for the 29 September run. Topics were chosen from qualitative signals: search autocomplete, titles published by many independent sites, Hacker News and GitHub issue threads, and video suggestions. No page on this site claims a search volume. When search data becomes available, it will be used to choose and rank the next pages.

Evidence gaps after the 29 September run

  1. No live behaviour. No integration was run against the real API. The danna-zhou hook's 401/403 path is read from code; whether TypeSafe rejects model: "kev-latest" is unknown.
  2. Unread dependencies and files. jkudish/jev-mcp's TypeSafe-direct transport (@jkudish/jev-agent-tools), jev-claude's rule list and Codex adapter, and oh-my-claudecode's per-point hook events were not read. The danna-zhou MCP server's behaviour on a hanging endpoint was not tested.
  3. SDKs not executed. The official JS SDK was not installed (the Node test mirrors its defaults in pool code); the Python SDK install is still not done. The AI SDK's default timeout is undocumented, and its first version with experimental_evaluate conflicts (7.0.103 by package contents, 7.0.105 in Vercel's guide).
  4. Access. The console still returns 403; the credit status rests on the 27 Sep CEO post and the absence of later statements.
  5. Scan coverage. Reddit, X, TikTok and Lobsters were blocked; YouTube, GitHub trending and GitHub code search were not attempted; new hook and MCP repositories are leads only.

Evidence gaps after release 1

  1. Account facts. Whether a new account gets any credit today, live quotas and an actual bill are unknown; the console returned HTTP 403 and the pool does not create accounts. No primary TypeSafe source gives the "$5 / 120M tokens" amount.
  2. No live Jev behaviour observed by the pool. Status codes, headers and rate-limit scope are reported by third parties; the SDK was not executed; model="jev-1.13" was not tested.
  3. Confidence. The Score confidence formula for 4 or more levels is unknown; the independent calibration tests each cover one dataset and one model version.
  4. Billing. Whether question and criteria text and failed requests are billed is undocumented; how OpenRouter's Jev Router bills the routed model, and what it does on failure, is undocumented.
  5. Data terms. OpenRouter's retention and logging for Jev, the text of TypeSafe's MCA, privacy policy and DPA, and the billing entity for direct accounts were not reviewed (planned for a later release).
  6. Resellers. jev-agent.com was not checked; jev-ai.pro's monthly prices were not visible; flagged lookalike repositories and Spaces were not opened.
  7. Production claims. TechCrunch's Vercel article was not checked; there is no primary source for a Notra claim; FundaAI's method is paywalled; VentureBeat was read only through a summarising tool.
  8. Videos. No frames or transcripts were viewed; several videos do not state the route or SDK; whether one trading video used a real key is unknown.
  9. Alternatives. Ollaya's per-model licences and benchmark origin, Laya's System One compatibility, Kev's base-model licences, and whether AnyJev is the catalogue's JevAny are unchecked; six new leads are unverified.
  10. Scan coverage. Reddit, X, TikTok, Lobsters and GitHub code search could not be read; DEV.to coverage is complete only for the jev tag; npm and Hugging Face counts are capped.
  11. Benchmarking terms. A tool author's claim that TypeSafe's agreement restricts publishing benchmark results was not checked.
