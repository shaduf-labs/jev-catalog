Jev (TypeSafe AI): can you use it today, and where to start

Jev is TypeSafe AI's model for bounded decisions: it picks from answers you define, scores against a rubric, or gives a yes probability. This site tracks whether you can get it, what it costs, what people build with it, what the published tests show and what to use instead. (Not the Japanese encephalitis virus, JEV.)

Short answer

Jev fits a repeated decision with a fixed set of answers (a queue, a label, a yes/no gate, a 2–10 level score) where your own code checks the answer and acts on it. It does not write text. TypeSafe lists it at $0.042 per million input tokens with free output (checked 8 Oct 2026, 05:14 UTC).

Published tests, all run by third parties or TypeSafe, put it ahead of cheap LLM setups that generate their answer as text, close to frontier LLM judges on verdicts that can be read off the text, and behind the best LLMs on harder judgments. None of the projects this site audited is independently verified as a working production deployment.
