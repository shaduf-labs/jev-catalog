Jev (TypeSafe AI) catalogue: use cases, alternatives, products, access and cost

This site answers practical questions about Jev, the TypeSafe AI model that returns bounded Choice, Score and Noul judgments. It is not about the Japanese encephalitis virus (JEV). Each page answers one question, gives a table or procedure you can act on, and labels every material claim by how it was checked.

Short answer

Jev fits a repeated decision with a fixed set of answers (a queue, a label, a yes/no gate, a 2–10 level score) where your own code checks the answer and decides what happens next. TypeSafe lists it at $0.042 per million input tokens with free output (docs, checked 28 Sep 2026). Several open projects call it in their source code, but none of the projects this pool audited has been independently verified as a working production deployment.

What changed

29 September 2026

  • Four new Build pages: a Build hub, TypeScript, Claude Code and MCP guardrails and testing without a key. Of five Jev guardrails read in source, only LangChain's AutoModeMiddleware stops the agent when Jev fails; the official TypeSafe plugin makes no Jev call.
  • Correction: oh-my-claudecode's Jev timeout was raised to 2000 ms only on its dev branch; the latest release, v5.5.0, still defaults to 250 ms (errors page).
  • Correction: the Products row "jev-mcp" is now "jev-mcp (jkudish)", grade A and advisory. At least four unrelated repositories share that name; five more audited integrations have their own rows (Products).
  • Access, prices, aliases and SDK versions were rechecked: no change since 28 Sep (29 Sep report).
28 September 2026
  • The site is now organised by reader question. Eight new pages cover access status, official vs reseller sites, cost per decision, Python, errors and rate limits, confidence thresholds, limitations and demo videos. Every earlier URL still works; see the old-to-new URL map and release notes.
  • Signups for Jev reopened on 27 Sep (22:33 UTC), but new users get no free credit for now (timeline).
  • Vercel's models API lists Jev at exactly $0.042 per million input tokens; OpenRouter also accepts TypeSafe's SDKs at /api/v1/systemone; OpenRouter's separate Jev Router routes to other models (route matrix).
  • Corrections: two project rows were wrongly labelled as official TypeSafe repositories, and a "250 ms default timeout" repeated online is not TypeSafe's (release 1 report).

What this site has not verified

  • No live Jev call, account bill, signup or credit balance. Prices are public listings.
  • No accuracy, calibration or latency benchmark run or rerun by the pool; third-party tests are labelled Reported.
  • No independently verified production deployment of any audited project.
  • No search-traffic data: page topics were chosen from qualitative demand signals because search analytics were still unavailable on 29 September 2026.
