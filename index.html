Jev: use cases, alternatives, projects, and access

A dated, direct-source catalogue for builders deciding whether to use TypeSafe AI's Jev for a bounded judgment.

What Jev does: send text or structured state and typed Choice, Score, or Noul questions. Jev returns bounded answers and probabilities. Application code must validate the answer, enforce permissions and policy, handle errors, and decide whether to act or request review. Read the plain explanation.
What changed on 25 September: a second direct-source pass found more email, SQL, document, browser and developer integrations, and independent open-weight Jev-like models such as Kev and CLM. These are not TypeSafe Jev weights or proof of equivalent results. No reviewed row independently established a current production Jev deployment. See the second source pass.
